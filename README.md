Description

The player is inside a room and must collect 3 keys to open the exit door and win.

After winning, the level restarts and the keys are placed in different locations.

Technologies

- Godot 4.7.1
- GDScript

Installation

1. Download or clone the project.
2. Open Godot.
3. Import the project.godot file.
4. Run the project.

Controls

 Z / Q / S / D or Arrow keys to move

E to collect the key

Features

- Player movement
- Wall collision
- Key collection system
- Random key placement after each win
- Door opening system
- Victory screen
- Sound effect
